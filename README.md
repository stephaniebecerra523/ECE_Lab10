## Lab Questions

### What is difference between edge and level sensitive circuits?
- Edge sensitive circuits respond only at the exact moment of a signal transition while level sensitive circuits respond continuously as long as the signal stays at a secific at a specific state. 

### Why is it important to declare initial state?
- It is important because it sets default cases. Without it, it has no way of knowing the state of any of the various pieces of memory within.

### What do edge sensitive circuits let us build?
- Edge sensitive circuits let us build flip-flops.
